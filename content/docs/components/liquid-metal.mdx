## API

| Property | Type | Description |
| --- | --- | --- |
| `speed?` | `number` | 1 is a slow drift |
| `tint?` | `[number, number, number]` | warms or cools the highlights, as r, g, b from 0 to 1 |
| `quality?` | `number` | 0.5 renders at half resolution, plenty for thin rims |
| `brightness?` | `number` | shifts the reflection toward the bright sky; 0.8 is mostly silver |
| `scale?` | `number` | below 1 makes the ripples broader, good for small or wide shapes |
| `softness?` | `number` | 0 is mirror chrome, 1 is soft brushed satin |
| `pattern?` | `"liquid" \| "silk"` | "silk" lays the ripples out as long diagonal folds |
| `maxAspect?` | `number` | wider than this width-to-height ratio, ripples stretch instead of repeating |

Standard element attributes are supported where the props extend a React element type. Required properties appear without a question mark.

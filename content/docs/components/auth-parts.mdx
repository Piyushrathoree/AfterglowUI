---
title: "Auth Parts"
description: "Shared pieces for auth forms: provider buttons with brand marks, fields, a divider and a submit hook."
---

These are shared form primitives, not an authentication backend. Field connects its label and error text; ProviderButton supplies a provider mark and accessible text.

## Installation

<InstallCommand name="auth-parts" />

## Usage

```tsx
"use client"

import {
  Field,
  Divider,
  ProviderButton,
} from "@/components/ui/auth-parts"

export default function Demo() {
  return (
    <div className="w-full max-w-xs space-y-5">
      <ProviderButton provider="google" />
      <Divider />
      <Field
        label="Email address"
        type="email"
        placeholder="you@example.com"
        autoComplete="email"
      />
    </div>
  )
}
```

## API

| Property | Type | Description |
| --- | --- | --- |
| `provider` | `Provider` | The provider option. |
| `verb?` | `string` | "Continue with", "Log in with"… |
| `lastUsed?` | `boolean` | a small "Last used" badge in the corner |

Standard element attributes are supported where the props extend a React element type. Required properties appear without a question mark.

## Dependencies

---
title: "Liquid Menu"
description: "A glass button that morphs into a menu, with full keyboard support."
---

Use triggerLabel for an icon-only trigger. The menu supports arrow keys, Home, End, Escape, and selection with Enter. onSelect connects each action to your application.

<InstallCommand name="liquid-menu" />

## Usage

```tsx
"use client"

import { useState } from "react"
import { Copy, Share, MoreHorizontal } from "lucide-react"
import { LiquidMenu } from "@/components/ui/liquid-menu"

export default function Demo() {
  const [action, setAction] = useState("Choose an action")
  return (
    <div className="min-h-64 space-y-6 pt-8 text-center">
      <LiquidMenu
        trigger={<MoreHorizontal />}
        triggerLabel="More actions"
        items={[
          {
            label: "Copy link",
            icon: <Copy />,
            onSelect: () => setAction("Link copied"),
          },
          {
            label: "Share",
            icon: <Share />,
            onSelect: () => setAction("Ready to share"),
          },
        ]}
      />
      <p className="text-sm text-muted-foreground" role="status">
        {action}
      </p>
    </div>
  )
}
```

## API

| Property | Type | Description |
| --- | --- | --- |
| `trigger` | `React.ReactNode` | what the closed button shows |
| `triggerLabel?` | `string` | accessible name for an icon-only trigger |
| `items` | `LiquidMenuEntry[]` | The items option. |
| `align?` | `"start" \| "end"` | which edge the menu grows from |
| `width?` | `number` | The width option. |

Standard element attributes are supported where the props extend a React element type. Required properties appear without a question mark.

---
title: "Sheen Card"
description: "A card that tilts toward your pointer while reflected light slides across it."
---

The card responds to the pointer with tilt and reflected light. Keep interactive content accessible without relying on the tilt.

## Installation

<InstallCommand name="sheen-card" />

## Usage

```tsx
"use client"

import { SheenCard } from "@/components/ui/sheen-card"

export default function Demo() {
  return (
    <SheenCard className="w-full max-w-sm rounded-3xl border p-10">
      <p className="text-sm text-muted-foreground">Afterglow studio</p>
      <h2 className="mt-3 text-3xl font-medium">
        A different perspective.
      </h2>
      <p className="mt-6 text-muted-foreground">
        Move your pointer across the surface.
      </p>
    </SheenCard>
  )
}
```

## API

| Property | Type | Description |
| --- | --- | --- |
| `maxTilt?` | `number` | The max tilt option. |
| `foil?` | `boolean` | The foil option. |
| `children?` | `React.ReactNode` | The children option. |

Standard element attributes are supported where the props extend a React element type. Required properties appear without a question mark.

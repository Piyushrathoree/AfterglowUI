---
title: "Gloss Button"
description: "A glossy button with a sheen, a pointer hotspot, and a press that squishes."
---

Use the ember variant for an emphasized action and glass for a secondary action. Standard button attributes are supported.

## Installation

<InstallCommand name="gloss-button" />

## Usage

```tsx
"use client"

import { GlossButton } from "@/components/ui/gloss-button"

export default function Demo() {
  return (
    <div className="flex flex-wrap justify-center gap-4">
      <GlossButton>Save changes</GlossButton>
      <GlossButton variant="glass">Cancel</GlossButton>
      <GlossButton disabled>Unavailable</GlossButton>
    </div>
  )
}
```

## API

| Property | Type | Description |
| --- | --- | --- |
| `variant?` | `keyof typeof surfaces` | The variant option. |
| `size?` | `keyof typeof sizes` | The size option. |
| `children?` | `React.ReactNode` | The children option. |

Standard element attributes are supported where the props extend a React element type. Required properties appear without a question mark.
